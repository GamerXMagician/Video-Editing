## OPTIMIZATION TIPS

**Images:**
- Max size: 200KB per image
- Use TinyPNG for compression
- Format: JPG for photos, PNG for graphics

**Performance:**
- Keep HTML under 50KB ✓ (currently 30KB)
- Keep CSS under 50KB ✓ (currently 26KB)
- Keep JS minimal ✓ (currently 9.4KB)
- Use PageSpeed Insights after launch

**SEO:**
- Update meta description
- Add keywords
- Submit to Google Search Console
- Create robots.txt

## SUPPORT QUICK LINKS

| Issue | Solution |
|-------|----------|
| Images not showing | Check file path, verify file exists |
| Links not working | Check URL format, test in browser |
| Colors not changing | Clear cache (Ctrl+Shift+R), verify CSS |
| Animations choppy | Check browser console for errors |
| Mobile looks broken | Use Chrome DevTools (F12) to test |
| Videos won't play | Check video is public, use HTTPS |

## FILE NAMING BEST PRACTICES

✅ Good:
- `project-name.jpg`
- `client-testimonial.jpg`
- `portfolio-images/`

❌ Bad:
- `Project Name.jpg` (spaces)
- `image_1.jpg` (underscore + number)
- `SCREENSHOT.JPG` (mixed case)
