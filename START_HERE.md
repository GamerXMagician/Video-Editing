## 🔧 EDITING QUICK REFERENCE

### Text/Content Changes
1. Open `index.html` in text editor
2. Press Ctrl+F to find text
3. Find and replace
4. Save (Ctrl+S)
5. Refresh browser (F5)

### Color Changes
1. Open `styles.css`
2. Find `:root {` at top
3. Change color values
4. Save (Ctrl+S)
5. Refresh browser (Ctrl+Shift+R)

### Image Changes
1. Save new images to `portfolio-images` folder
2. Update file names in `index.html`
3. Verify images display
4. Save and refresh

### Testing Locally
1. Open `index.html` in web browser
2. Changes show immediately
3. Use F12 (DevTools) to inspect
4. Mobile view: Ctrl+Shift+M

## ❓ FAQ

**Q: Can I edit this without coding knowledge?**
A: Yes! Use Find & Replace (Ctrl+F) to change text. See CUSTOMIZATION.md for locations.

**Q: What if I break something?**
A: Keep a backup copy. Changes don't affect the original unless you save over it.

**Q: How do I add more portfolio projects?**
A: Copy one portfolio-item div in index.html. See CUSTOMIZATION.md for details.

**Q: Can I change the colors?**
A: Yes! Edit CSS variables at top of styles.css. See QUICK_REFERENCE.md for presets.

**Q: How long until it's live?**
A: 1-2 hours customization + 5 minutes to deploy = online today!

**Q: What if I don't have my portfolio images yet?**
A: Launch with placeholders. Update later. Professional portfolio > waiting for perfect images.

**Q: Can I use this for other purposes?**
A: Yes! It's a flexible template. Customize for any creative service.
